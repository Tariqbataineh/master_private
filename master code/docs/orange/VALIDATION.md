## Practical limits
Tests use Chromium with software WebGL in this environment. Synthetic touch is not a physical-device test; Safari, iOS and a range of GPU hardware have not been verified. No live authentication/payment/business-endpoint smoke test was performed: those source files are byte-identical, which provides preservation evidence, not a claim that external services were retested. No FPS guarantee or universal zero-bug claim is made. The browser diagnostic run observed economical batched interior rendering (29 draw calls and about 16.4k visible triangles in one room before final material-cache optimization); counts vary by view and shadows.

The architecture is conceptually arranged from the written requirements and informed by both supplied videos. The footage is not a measurement survey. Kitchen/restroom fixtures, unseen room boundaries, dimensions and furniture placement are estimates. Generic people are economical stylized models with asynchronous small motion. Accessibility fixtures are illustrative, not certified. See `LAYOUT_AND_REFERENCES.md`.
