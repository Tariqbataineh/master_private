# Wusool — النسخة الموحّدة v27

هذه النسخة تعتمد نظام v24 الأخير كاملًا، مع استكشاف أورانج والطريق والمباني الأربعة من v26. استخدم هذه النسخة بدل v25/v26.

تم استرجاع حجز التذاكر بنفس الواجهة واللوجيك السابق: إنشاء التيكت، اختيار خدمات الفرع، طلب المساعدة والسعة، التتبّع والخريطة، التعديل والإلغاء مع السبب، QR، والتقييم وفق الحالة والصلاحية. كما تم استرجاع صفحات المستخدم والمؤسسة والإدارة، إدارة الخدمات، الخرائط، الترجمة، الثيمات والوظائف المشتركة من آخر نسخة v24. لا تصفير للتخزين أو تغيير لعقود API.

المباني الأربعة محفوظة ضمن الطريق، وأورانج بنفس ترتيب الغرف والتحكم السلس والرجوع للممر. لم يتم تركيب جولة أورانج القديمة فوق الجولة الحالية.

## التشغيل
فك ZIP، وافتح terminal داخل master code، ثم شغّل `python3 -m http.server 8000` أو Live Server وافتح http://localhost:8000/visitor/html/home.html . لا تحتاج Node لتشغيل الموقع. لا تستخدم file://.

الحجز من حساب المستخدم: My Tickets → Create ticket. سجّل بيانات الفرع الحقيقية وخدماته وحالة نشره بالطريقة السابقة. مؤسسات الطريق محطات عرض؛ الحجز مرتبط بفروع منشورة حقيقية وليس بسجلات وهمية.

## التحقق والمرفقات
`docs/restoration-v27.json` يقارن ملفات النظام حرفيًا مع v24، ومسارات أورانج مع v26. `docs/validation-v27.md` يحتوي نتائج الاختبارات الحالية وحدودها. صور الحجز تحت docs/screenshots-v24، ومخطط أورانج وصور غرفه تحت docs/orange.

لإعادة الاختبارات: `npm install` ثم `npm test`. فحص الواجهة: `npx playwright install chromium` ثم `npm run test:browser`. مسارات أورانج: `node tests/orange/navigation.test.mjs`. يمكن تعيين WUSOOL_CHROMIUM أو CHROMIUM_PATH لمسار Chromium مثبت.

وثائق v24/v25/v26 المرفقة تاريخية وتشرح التعديلات السابقة. هذه تعليمات النسخة الحالية. إعداد API وGoogle Maps كما في v24؛ الاختبارات المعزولة لا تثبت صلاحية المفتاح أو تشغيل backend خارجي. المشروع frontend كما هو.
